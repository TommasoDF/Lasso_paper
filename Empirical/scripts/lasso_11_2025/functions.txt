lasso_rolling_window(X, y, window_size, n_lags, lambda_mode, fixed_lambda)

    - estimates 1st stage lasso for given window size, lag number and lambda_val
    - internally lags X using helper create_lagged_features()
    - output: results dataframe with one row = one rolling window estimation results

estimate_single_config(X, y, window_size, n_lags, lambda_val)

    - estimate 1st and 2nd stage for one combination of l,n,lambda
    - use lasso_rolling_window from stage1.py
    - use def calculate_r_squared from stage1.py to get r2_oos for 1st stage
    - define inputs for 2nd stage (return from data, predicted return from stage 1)
    - use compute_stage2_r_squared() from stage2.py to estimate alm
    - returns two dicts: (1) 'summary' with metrics for the overall configuration including r2 for both stages and kappa (2) 'details' estimation results for each window

compute_alm_returns(predicitons, kappa, intercept)

    - calculate returns with the estimated ALM
    - inputs: plm returns from 1st stage, kappa, intercept
    - output: alm returns

estimate_kappa_curve_fit(stage2)

    - used inside of compute_stage2_r_squared() to estimate the nonlinear ALM 
    - takes realized returns, and agents x_t beta_t and x_t+1 beta_t+1 to estimate kappa
    - returns popt: kappa and intercepte and pcov: covariance matrix

compute_stage2_r_squared(stage2_input, min_train_size=100)

    - estimates the ALM using estimate_kappa_curve_fit()
    - calculate predicted ALM returns using compute_alm_returns(predicitons, kappa, intercept)
    - calculate in-sample r2 2nd stage using calculate_r_squared() from stage1.py and input actual returns, alm returns
    - calculate oos r2 2nd stage by splitting sample into train (first 80%) and test (last 20%); 
      estimate alm on train sample, then generate forecasts for test sample; r2 is then calculated using forecasts and actual values
